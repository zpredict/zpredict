# zpredict-plugin-polymarket

Mirrors a binary Polymarket market: same question, traded privately on zPredict's own book. YES iff Polymarket resolved "Yes" to 1; No or a 50-50 settlement resolves NO. Polymarket (UMA) is the oracle: each relayer reads the public Gamma API on its own, and the outcome is signed only when all three agree.

Params: `{"conditionId": "0x…", "slug": "will-…"}`. The catalog in `deploy/production/relayer.toml` is generated by `scripts/polymarket-catalog.mjs`.

```sh
cargo test -p zpredict-plugin-polymarket
```
